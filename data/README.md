# Data

This folder contains the datasets used for the logistics data analysis project.

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset can be downloaded from Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Important

The raw dataset files are not included in this repository. Download the dataset and place the CSV files inside this directory when running the notebooks locally.
