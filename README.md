# Logistics Data Analysis & Route Optimization

## Project Overview

This project explores how data science and machine learning can be applied to improve e-commerce logistics operations.

The project focuses on analysing historical delivery data to understand delivery performance, identify factors contributing to delays, segment customers and regions, and explore route optimization strategies.

The analysis uses Python-based data science techniques to transform raw logistics data into actionable insights for supply chain decision-making.

---

##  Project Objectives

The main objectives of this project are:

1. Analyse historical e-commerce logistics data.
2. Measure key logistics performance indicators (KPIs).
3. Identify factors associated with delivery delays.
4. Explore relationships between freight cost, distance, and delivery time.
5. Develop a machine learning model to predict late deliveries.
6. Segment customers or regions based on logistics behaviour.
7. Develop a prototype vehicle route optimization model.
8. Translate analytical findings into practical logistics recommendations.

---

## 📊 Key Performance Indicators

The following KPIs will be used to evaluate logistics performance:

| KPI | Description |
|---|---|
| On-Time Delivery Rate | Percentage of orders delivered on or before the estimated delivery date |
| Average Delivery Time | Average time taken from order placement to delivery |
| Late Delivery Rate | Percentage of orders delivered after the estimated delivery date |
| Freight Cost per Order | Average freight/transportation cost per order |
| Average Review Score | Average customer review score |
| Route Distance | Total distance travelled during delivery |

## Dataset

This project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The dataset contains approximately 100,000 orders from 2016 to 2018 and includes information about:

- Orders
- Customers
- Sellers
- Products
- Payments
- Reviews
- Freight
- Geolocation

The dataset will be used to investigate relationships between geography, delivery performance, transportation cost, and customer satisfaction.
